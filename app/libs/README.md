# Nothing Glyph Matrix SDK

Download `glyph-matrix-sdk-2.0.aar` from Nothing's official
[Glyph Matrix Developer Kit](https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit)
and place it in this directory.

The AAR is intentionally ignored because Nothing's SDK licence prohibits
redistribution. By downloading or using it, you agree to Nothing's licence.
